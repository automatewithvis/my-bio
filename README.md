## 💻 Featured Project

### 🤖 My Personal Assistant

An AI-powered personal assistant built with **n8n, Google Gemini, Telegram, Gmail, Google Calendar, and Tavily**.

The assistant can understand **text and voice messages**, maintain conversational memory, manage calendar events, send emails, and perform web research through a single Telegram interface.

### ✨ Highlights

- 🎙️ Voice + text interaction
- 🧠 AI Agent with conversational memory
- 📅 Google Calendar automation
- 📧 Gmail automation
- 🌐 Tavily-powered web research
- 🔄 Multi-tool AI workflow orchestration
